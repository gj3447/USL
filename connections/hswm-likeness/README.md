# HSWM_LIKENESS session connection

`hswm-session-2026-10-06` is the fixed USL connection ID for the 2026-10-06
HSWM_LIKENESS session graph. The graph and its domain profile are generated by
the HSWM_LIKENESS repository, where they remain host-local evidence under
`.local/usl/session-2026-10-06/`. This directory keeps only the portable,
credential-free MCP registration.

From `HSWM_LIKENESS`, refresh the graph before consuming it:

```sh
npm run usl:session -- refresh
```

From the USL checkout, start a fresh read-only stdio server:

```sh
npm run usl -- mcp --config connections/hswm-likeness/session-2026-10-06.json
```

Connection-aware USL operations such as `check`, `compile`, `context`,
`observe`, and `project` use `connection: "hswm-session-2026-10-06"`. For
example, the MCP `context` input uses a graph resource ID as `query.focus`:

```json
{
  "connection": "hswm-session-2026-10-06",
  "query": { "focus": "urn:hswm:session:2026-10-06:session" },
  "compact": true
}
```

The HSWM_LIKENESS runner also accepts durable aliases for common entry points:

```sh
npm run usl:session -- context google
npm run usl:session -- evidence google
npm run usl:session -- get google
```

The empty `allowedLocators` list intentionally makes observations deny-all by
default. This registration connects a bounded graph for navigation and
validation; it does not grant filesystem access, create an HSWM admission, or
establish measured efficacy.
